AtomicSats Reference Implementation - Developer Guide

Status: Phase 0 – Initial Setup (structure only)

Goal

Build a minimal, correct, and easy-to-audit implementation of the AtomicSats exchange primitive so we can demonstrate real sats-for-block trading on testnet.

Project Layout (this folder)

atomicsats/
├── go.mod
├── README_DEV.html       ← You are here
├── cmd/
│   └── atomicsats/       ← Main executable (CLI for testing)
├── internal/
│   ├── handshake/        ← Core four-message logic
│   ├── lightning/        ← Lightning client wrapper (LND)
│   ├── cidstore/         ← Local block storage by CID
│   └── records/          ← Host Registry & Records Database stubs
├── proto/                ← Message definitions (if using protobuf)
└── test/                 ← End-to-end tests (regtest)

Quick Start (for future contributors)

git clone https://github.com/chadlupkes/IPFS-Sats.git
cd IPFS-Sats/implementation/atomicsats
go mod tidy
go run ./cmd/atomicsats

  • Prefer simplicity and auditability over cleverness.
  • Test everything on Lightning regtest or signet first.
  • Open issues or PRs — Chad will review for protocol alignment.
